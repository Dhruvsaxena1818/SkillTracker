# SkillTracker LMS

Frontend-only Learning Management System built with HTML, CSS and Vanilla JavaScript.

## Run
1. Extract the ZIP.
2. Open the `lms pro` folder in VS Code.
3. Install/use the VS Code **Live Server** extension.
4. Right-click `html/login.html` and choose **Open with Live Server**.

## Notes
- This is a frontend demonstration. Authentication is simulated in the browser using LocalStorage.
- Do not use this demo authentication for real users or sensitive information.
- App data is stored in JavaScript and browser LocalStorage. No JSON files or backend are used.
